## Instructions

1. **Drag and drop** your photos and videos into the appropriate folders
2. **Supported formats**: JPG, PNG, GIF, WebP, MP4, MOV
3. **File naming**: Use descriptive names (e.g., `arena-build-day1.jpg`, `premium-stable-interior.jpg`)
4. Once uploaded, let me know and I'll review them and select the best ones for each page

## Tips for Best Results

- **High resolution**: 1920px width minimum for hero images
- **Landscape orientation**: Works best for galleries and hero sections
- **Good lighting**: Natural light photos work best
- **Clear subjects**: Focus on the craftsmanship and details
- **Action shots**: Photos with activity tell better stories
